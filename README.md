# AutodocNews

iOS-приложение для просмотра новостной ленты Autodoc. Тестовое задание.

---

## Стек технологий

- **UIKit** — вёрстка без Storyboard, только код
- **MVVM + Combine** — архитектура и реактивные биндинги
- **UICollectionView + CompositionalLayout + DiffableDataSource** — лента новостей
- **async/await** — все сетевые запросы
- Только стандартные фреймворки Apple без сторонних зависимостей

## Возможности

- Постраничная загрузка новостей (15 за раз), подгрузка при скролле
- Отображение изображения и заголовка в ячейке
- Детальный экран с полным текстом новости
- Pull-to-refresh
- Shimmer-анимация на время загрузки картинок
- Обработка ошибок сети с возможностью повторить запрос

## Оптимизация для iPad

- Адаптивная сетка: 1 колонка на iPhone, 2 на iPad portrait, 3 на iPad landscape
- Автоматическое переключение при повороте экрана

## Источник данных

```
GET https://webapi.autodoc.ru/api/news/{page}/{pageSize}
```
